# bb_id
Script that shows your server id.

## Features
- When player talks id changes colour.
- You can set radius that you will see id in.

## Preview
![id2](https://github.com/user-attachments/assets/3dc1a318-a26d-48ce-b4d6-9e5f00ece516)

## How to install
Put this script in your resourcers folder and start it after your voicechat script.
